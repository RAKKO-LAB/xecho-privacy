プライバシーポリシー（Xecho）

制定日：2026年10月26日

RAKKO-LAB（以下「当方」）は、Android アプリ「Xecho」（以下「本アプリ」）における利用者の情報の取り扱いを、以下のとおり定めます。

1. 本アプリがすること

本アプリは、X（旧 Twitter）の公式 Android アプリで利用者が画面に表示した投稿を、Android のユーザー補助機能（Accessibility API）を使って読み取り、利用者の端末内にだけ記録します。記録した投稿は、本アプリの中で読み返すことができます。

本アプリは X Corp. とは関係のない非公式のアプリです。

2. 読み取る情報

本アプリが読み取るのは、利用者がユーザー補助の設定で本アプリを有効にしている間に、X の公式アプリ（パッケージ名 com.twitter.android）の画面に表示された内容だけです。他のアプリの画面は読み取りません。

読み取って保存する項目:

  • 投稿の表示名・ユーザー名（@から始まる名前）・本文・引用された投稿の表示名と本文
  • 投稿時刻の表示（「3時間」など）から推定した投稿時刻
  • 返信・リポスト・いいね・表示回数として画面に出ていた数
  • 画像の枚数・動画の有無（画像や動画そのものは保存しません）
  • 広告表示かどうか、リポストした人・返信先として画面に出ていた名前
  • 利用者が各投稿を画面に表示した日時と回数
  • 動作確認のための記録（読み取りの成否・画面の種類・日時。投稿の本文・名前は含みません。7日分だけ保持）

本アプリは、X に対して操作（タップ・スクロール・いいね・投稿など）を一切行いません。

3. 情報の保存場所と外部への送信

  • 記録はすべて利用者の端末内に保存されます。
  • 本アプリはインターネット接続の権限を持っていません。そのため、記録が当方や第三者のサーバーに送られることはありません。
  • 当方が利用者の記録を見ることはできません。
  • 端末のバックアップ機能（Google のバックアップ等）の対象にもしていません。

4. 利用者による書き出し

本アプリの設定画面には、記録を JSON ファイルとして書き出す機能（一部の版のみ）、および動作確認の記録（投稿の本文・名前を含みません）を書き出す機能があります。書き出しは利用者が操作したときだけ行われ、保存先は利用者が Android のファイル選択画面で選びます。書き出した後のファイルの管理は利用者に委ねられます。

5. 保存期間と削除

  • 保存期間は設定画面で選べます（30日 / 90日 / 無期限。初期値は無期限）。
  • 投稿は1件ずつ、または設定画面からすべて削除できます。
  • 本アプリをアンインストールすると、端末内の記録はすべて削除されます。

6. 使用する権限

  • ユーザー補助サービス（BIND_ACCESSIBILITY_SERVICE）: 第2項の読み取りのため。利用者がユーザー補助の設定で有効にしたときだけ動作し、いつでも無効にできます。
  • 通知（POST_NOTIFICATIONS）: 記録が止まっていることを知らせるため。

7. 第三者への提供

当方は利用者の情報を取得しないため、第三者に提供することはありません。

8. 子どもの利用

本アプリは18歳未満の方を対象としていません。

9. 免責事項

10. 本ポリシーの変更

本ポリシーの内容は変更することがあります。変更後のポリシーは、本ページに掲載した時点から効力を生じます。
